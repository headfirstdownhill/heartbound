THE LETTERS
===========

Every letter in the game is one file in this folder. That is all they are.
Plain text, nothing clever, nothing you can break by typing in it.


TO ADD A NEW ONE
----------------

1. Right-click _TEMPLATE.txt and choose Copy. Right-click in the empty
   space in this folder and choose Paste.

2. You will get a file called "_TEMPLATE - Copy.txt". Rename it to the
   next number up. If the newest letter here is letter2.txt, call yours
   letter3.txt

   To rename: right-click it, choose Rename, type the new name, Enter.
   Make sure it still ends in .txt

3. Open it (double-click, or right-click and Open with Notepad).

4. First line is the date he sent it, like this:

       Saturday 12/09/2026

   The day name has to match the actual date. If you get it wrong the
   tool tells you and says what it should be.

5. Leave a blank line, then paste what he wrote.

6. Put a blank line between paragraphs. EACH PARAGRAPH BECOMES ONE PAGE
   of the letter. That is the only rule, and it means where the pages
   break is always your choice.

7. Save it. In Notepad: File, then Save.

8. Go back to the main folder and double-click ADD-LETTER.bat


THINGS YOU DO NOT NEED TO WORRY ABOUT
-------------------------------------

Paste his message exactly as he sent it. Do not try to tidy it up.

The tool sorts out the curly apostrophes, the long dashes, and the
emoji all by itself, and tells you what it did. You do not need to
know or care about any of that.


TO CHANGE A LETTER THAT IS ALREADY IN THE GAME
----------------------------------------------

Open its file, change it, save it, and double-click ADD-LETTER.bat
again. It replaces the old version.


TO REMOVE A LETTER
------------------

Delete its file, then double-click ADD-LETTER.bat again.

Careful: that is the only copy of his words. If you might want it back
one day, move the file somewhere else instead of deleting it.


IF SOMETHING GOES WRONG
-----------------------

ADD-LETTER.bat never half-does anything. Either it works, or it tells
you what is wrong and changes nothing at all. The game cannot be broken
by anything you type in these files.

There is a much longer guide in the main folder called LETTERS.md
